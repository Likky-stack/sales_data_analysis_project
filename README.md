# Sales Data Analysis Project

This project performs exploratory data analysis (EDA) on e-commerce sales data using Python.

## Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn

## Key Tasks

* Data cleaning
* Handling missing values
* Datetime conversion
* User interaction analysis
* Monthly trend visualization

## Insights

* Identified user behavior (views, likes, purchases)
* Analyzed engagement trends over time
