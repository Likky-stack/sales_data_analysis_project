# Sales Data Analysis Project

## 🎯 Objective

To analyze e-commerce user interaction data and identify patterns in customer behavior such as views, likes, and purchases.

## 📌 Overview

This project performs exploratory data analysis (EDA) on e-commerce sales data using Python to understand user engagement and trends.

## 🛠 Tools Used

* Python
* Pandas
* Matplotlib
* Seaborn

## 📂 Dataset

The dataset contains:

* user_id
* product_id
* interaction type (view, like, purchase)
* timestamp

## 📊 Key Tasks

* Data cleaning
* Handling missing values
* Datetime conversion
* User interaction analysis
* Monthly trend visualization

## 📈 Insights

* Identified user behavior patterns (views, likes, purchases)
* Analyzed engagement trends over time
* Observed how user activity changes monthly

## 🚀 Future Improvements

* Product-level analysis
* Conversion rate analysis (view → purchase)
* Customer segmentation
